# AI Platform — Frontend

A modern, customizable AI platform built with **Angular**, designed to provide an interactive conversational experience powered by Ollama models.

## Overview

This project is the frontend of an AI-powered application that allows users to interact with AI models through a clean, customizable, and user-friendly interface. It connects to a backend API to manage authentication, conversations, user preferences, and AI-powered features.

## Features

- **User Authentication:** Secure login and registration.
- **Email Verification:** Verification codes sent directly to users' email addresses.
- **AI Chat Interface:** Interactive conversations powered by Ollama models.
- **Conversation History:** Access and manage previous messages.
- **Image AI Integration:** Support for image-related AI functionality.
- **Customizable UI:** Personalize the application's interface and appearance.
- **User Management:** Personalized experiences based on individual user accounts.
- **API Integration:** Communication with the backend for authentication, messaging, and AI features.
- **Responsive Design:** An interface designed for a smooth user experience across different screen sizes.

## Tech Stack

- **Angular** — Frontend framework.
- **TypeScript** — Application logic and type safety.
- **HTML5 & CSS3** — Structure and styling.
- **REST API** — Communication with the backend.
- **Ollama** — AI model integration through the backend.

## Architecture

The frontend communicates with the backend API, which handles authentication, user data, conversation management, and interactions with AI models.

```text
Angular Frontend
       |
       v
   Backend API
       |
       v
  Ollama Models
```

## Getting Started

### Prerequisites

- Node.js
- npm
- Angular CLI
- A running instance of the backend API

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_FRONTEND_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd YOUR_FRONTEND_DIRECTORY
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   ng serve
   ```

5. Open `http://localhost:4200` in your browser.

### Configuration

Configure the backend API URL in the appropriate environment file before running the application.
